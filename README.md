## 🌟 Key Portfolio Features

1. **3D Miniature Island City**:
   - High-rise skyscrapers with illuminated window bands and rooftop antennas.
   - Suburban townhouses with pitched red roofs, chimneys, and streetlamps.
   - Autonomous flying drone patrolling the city skyline.
   - Animated wind turbines on the mountain ridge.
   - Continuous Catmull-Rom spline road connecting all 5 stations.

2. **Bicycle & Rider Physics**:
   - Carbon black bicycle with crimson racing stripes and glowing red wheel rims.
   - Steer lean physics, rotating wheel spokes, and dynamic leg pedaling animations.
   - **Nitro Boost Mode** (`Shift` key or on-screen mobile `NITRO` button) with flame exhaust particles and camera speed FOV warp.

3. **Automatic Station Information Pop-ups**:
   - Riding up to any station automatically opens the complete, detailed modal for that page:
     - 🏡 **Station 01 (About)**: Candidate snapshot, philosophy, core competencies, and resume download.
     - ⚡ **Station 02 (Skills)**: Categorized technical skills (Languages, Frontend, Backend, Databases, Tools, CS Core).
     - 🚀 **Station 03 (Projects)**: 4 live deployed production applications with 1-click live demo launch buttons.
     - ⛰️ **Station 04 (Experience)**: LebMentix (6 mo), Prodigy InfoTech, TCS, Deloitte Cyber & Data, B.Tech CSE (CGPA 7.10).
     - 🏁 **Station 05 (Contact)**: Confetti celebration, copy-to-clipboard email, social links, resume download, and message form.

4. **Recruiter 1-Pager Mode ("Skip the Ride")**:
   - Instant toggle for recruiters and hiring managers who need fast, executive, ATS-friendly document access without playing the game.

5. **Procedural Web Audio**:
   - Mechanical bicycle ticking, checkpoint discovery chimes, and finish line celebration fanfare synthesized via the Web Audio API (0 audio asset downloads).

## 💻 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/lalit-1608/Portfolio.git

# Navigate into project directory
cd Portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```
